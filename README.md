# Web con editor

Plantilla técnica de Repeat para webs nuevas: Astro, Keystatic y el acceso del
cliente a su editor. No trae diseño: es la base sobre la que se hace cada web.

- `npm install && npm run dev` y abre `http://localhost:4321` (el editor, en
  `/keystatic`, funciona en local sin claves).
- Se crea, se publica y se da de alta con el conector de Repeat Clientes desde
  Claude Code o Codex: pide la receta «web nueva» (`receta_web`).
